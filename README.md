# Calculator Frontend

一个使用原生 HTML、CSS 和 JavaScript 编写的计算器前端。

本项目负责表达式输入、结果展示和历史记录交互，实际的表达式解析与计算由后端服务完成。

## 功能

- 输入数字、四则运算符、小数点和括号
- 支持直接在输入框中编辑表达式
- 清空表达式和删除最后一个字符
- 调用后端接口计算表达式
- 在页面内显示计算结果或错误信息
- 通过侧边栏查看历史记录
- 删除单条历史记录并自动刷新列表
- 响应式布局，适配桌面端和移动端

## 技术栈

- HTML5
- CSS3
- 原生 JavaScript
- Fetch API

项目不依赖 npm、前端框架或构建工具。

## 运行项目

### 1. 启动后端

前端默认访问以下后端地址：

```text
http://127.0.0.1:8080
```

请先确保计算器后端已经启动，并允许前端页面所在地址进行跨域请求。

如需修改后端地址，请编辑 `js/api.js` 中的 `API_BASE_URL`。

### 2. 启动静态文件服务

项目无需安装依赖。可以在项目根目录使用任意静态文件服务器，例如：

```powershell
python -m http.server 5500
```

随后在浏览器中打开：

```text
http://127.0.0.1:5500
```

也可以使用编辑器提供的 Live Server 等静态服务工具打开 `index.html`。

## 后端接口约定

### 计算表达式

```http
POST /api/calculate
Content-Type: application/json
```

请求体：

```json
{
  "expression": "1+(2*3)-5"
}
```

前端从响应中的 `result` 字段读取计算结果：

```json
{
  "result": 2
}
```

### 查询历史记录

```http
GET /api/history
```

当前前端期望返回一个历史记录数组：

```json
[
  {
    "id": 1,
    "expression": "1+2",
    "result": 3,
    "created_at": "2026-10-06 10:00:00"
  }
]
```

### 删除历史记录

```http
DELETE /api/history/{id}
```

删除成功后，前端会重新请求 `GET /api/history`，以保证页面与后端数据一致。

所有接口都应返回可解析的 JSON。请求失败时，前端优先显示响应中的 `error` 字段。

## 代码组织

页面依次加载以下脚本：

1. `api.js`：封装计算、查询历史和删除历史请求。
2. `ui.js`：维护原始表达式并更新结果、错误和历史记录界面。
3. `app.js`：绑定按钮、输入框和历史记录面板事件。

脚本之间通过全局函数协作，因此请保持上述加载顺序。

## 当前范围

前端不负责数学表达式解析、运算符优先级判断、除零判断或历史记录持久化。当前版本也未包含科学计算、历史搜索、分页、批量删除和主题切换。

更详细的设计说明请参阅 [`docs/前端设计文档_v1.md`](docs/前端设计文档_v1.md)。
